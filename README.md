# Auction House - [LNbits](https://lnbits.com) extension

Auction digital goods and services for bitcoin. Create auctions, set starting prices, and let the market decide what your items are worth.

## How it works

Sellers create auction listings with a description, starting price, and duration. Bidders place bids using lightning payments. When the auction ends, the highest bidder wins and the seller receives the funds.

## Features

- Create timed auctions with customizable duration
- Set minimum bid increments
- Automatic winner selection
- Shareable auction pages

## Usage

1. Enable the extension in LNbits
2. Create a new auction with title, description, and starting price
3. Set the auction duration
4. Share the auction link with potential bidders
5. Collect payment from the winning bid
